# 요구사항 정리

와이어프레임(Figma) 화면들을 기반으로 정리한 요구사항. 화면 번호는 Figma 프레임 라벨 기준.

## 채팅 기능

1. 기본적인 채팅 기능 (5.1.1.1 메시지 입력)
2. 채팅방 목록 조회 — 팀원 이름 나열로 방 이름 자동 생성 (5.1 채팅목록)
3. 채팅방에서 프로필 클릭 시 팀원 프로필 조회 (5.1.2.2.3 팀원 프로필 열람) — 비공개 프로필이면
   "비공개 프로필입니다" 안내만 노출 (Profile.isPublic 그대로 사용)
4. 협업 후기는 프로젝트 종료일 이후 작성 가능 (5.1.1.2.2 협업후기 작성) — **이번 스코프에서는 보류**
5. 대화상대 조회 (5.1.2 메뉴_챗봇 삭제/추가 화면의 리스트)
6. 사용자 신고 — 신고 사유 선택 후 제출, 기타 선택 시 직접 입력 (5.1.2.2 팀원 신고)
7. 챗봇 삭제 / 추가 (5.1.2 메뉴_챗봇 삭제, 5.1.2.3 채팅봇 추가)
8. 채팅방 나가기 — 나가면 협업거리 10m 감소 (5.1.2.4 채팅방 나가기)
9. 공모전 후보 추가 (5.1.4 공모전 후보 추가)
10. 후보 공모전 리스트 조회 (5.1.3.3 팀 공모전 후보 리스트)
11. 후보 공모전 투표 — **다중선택(2개)**. 투표 참여자가 0명이면 AI가 대신 골라줌 (투표결과_미투표 화면)
12. 공모전 투표 동률 시 재투표 (공모전 동률 화면)
13. 추천 공모전 리스트의 "전체보기" → 후보 공모전 리스트로 이동 (확인 완료)
14. 채팅방 설정 — 상세 스펙 미정 (추후 확인)

## 챗봇 요구사항

1. 팀 매칭 완료 시 자기소개/인사 유도 (5.1.3.1 팀 인사 유도)
2. `@챗봇`으로 말 걸기 가능 (역할 분담 추천, 타임라인 추천 등) — 5.1.3.4 챗봇 활용 안내
3. 인사가 끝나면 팀장 선출 단계로 진행
4. 팀장 선출은 매칭 시점의 `PersonalityProfile.leaderPreferenceScore`(팀장 희망 여부)를 기준으로
   3가지 경로로 분기 — 상세는 [02-leader-election.md](./decisions/02-leader-election.md)
5. 팀장 선출 완료 후 팀 공모전 추천/투표로 진행 (팀 카테고리 기준 AI 추천)
6. 공모전 확정 후 마무리 멘트 + 챗봇 활용 예시 안내
7. 중간점검 — 팀 생성일과 공모전 마감일의 중간 날짜에 진행률을 팀 내에서 체크해보라는 안내
   메시지 발송 (응답/버튼 없는 일반 챗봇 메시지, 2026-08-18 변경)
8. 공모전 마감 하루 전 제출 여부 확인 — 팀장만 "진행 완료" / "미완료" 선택 가능. 진행 완료 선택 시
   팀 프로젝트 종료, 팀원 리뷰 단계로 이동 (리뷰는 보류)
9. 팀장 미선출/미투표 시 랜덤 임시 팀장 지정, 이후 언제든 팀장 변경 가능 (변경 시 챗봇에게 알려야
   베네핏 정상 지급 — 이 부분은 "팀장 변경" 기능으로 후속 스코프)

## 협업거리 포인트 이벤트 (확인된 것)

| 이벤트 | 변화량 |
|---|---|
| 채팅방 중도 이탈 | -10m |
| 프로젝트 완주 (팀원) | +20m |
| 프로젝트 완주 (팀장) | +30m |
| 팀원 리뷰 작성 | +10m (보류 기능이라 연결은 나중) |

매칭 신청 시 현재 `Member.collaborationPoint`를 `MatchingApplication.collaborationDistance`에
스냅샷으로 저장한다. 신청 후 회원의 협업거리가 변해도 과거 신청 값은 바뀌지 않는다.
자세한 내용은 [06-collaboration-point.md](./decisions/06-collaboration-point.md) 참고.
